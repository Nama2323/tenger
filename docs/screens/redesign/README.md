# R1 redesign: before and after

Captured with `docs/screens/capture.mjs` (headless Chrome, measured viewport, prefers-reduced-motion forced so
nothing is mid-animation) at 390 × 844 and 1440 × 900 CSS pixels.

- `before-*.png`: the B2 interface (14 Nov 2026, before task R1), still close to the SPHEREx Blink look.
- `after-*.png`: the R1 "mission console" design. `extra/` adds the open target sheet, Makemake in preview mode
  and the What changed panel.
- `*viewport-report.json`: per capture, the measured `innerWidth`, horizontal overflow, controls under 44 px and
  script errors.

Pages: `home` (real index), `home-fixtures-map` (example fixtures), `investigate-barnard` (real Barnard
investigation), `investigate-barnard-swipe`, `game-example-revealed` (example round after the full reveal),
`learn`, `about`. Screenshots show the real app; they are not evidence of validated science.
