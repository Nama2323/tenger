# Fonts

Self-hosted, latin subset, variable weight 400–700, WOFF2. Downloaded 14 Nov 2026 from Google Fonts
(`fonts.gstatic.com`, the files the Google Fonts CSS API serves for the latin subset). The licence texts come
from the `google/fonts` repository (`ofl/<family>/OFL.txt`).

| File | Family | Use | Licence |
|---|---|---|---|
| `space-grotesk-latin.woff2` | Space Grotesk (Florian Karsten) | headings | SIL Open Font License 1.1, `OFL-SpaceGrotesk.txt` |
| `inter-latin.woff2` | Inter (Rasmus Andersson) | text | SIL Open Font License 1.1, `OFL-Inter.txt` |
| `jetbrains-mono-latin.woff2` | JetBrains Mono (JetBrains) | numbers and coordinates | SIL Open Font License 1.1, `OFL-JetBrainsMono.txt` |

Characters outside the latin subset (for example μ, σ, ≈, ← →) fall back to the system fonts in the stack.
